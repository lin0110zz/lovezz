# 💖 Lovezz —— 移动端个人纪念音乐网页

> 项目代号：`lovezz810`（text-main-BV-mobile-adapted）
>
> 一个以粉色系、毛玻璃和可爱贴纸为视觉风格的移动端网页礼物：从一句「surprise❤」开始，进入一张可以滑唱片、搜歌、建歌单、甚至把 B 站视频变成音频的音乐卡片。
>
> 补药拷打我的代码 TVT

## ✨ 功能一览

### 🎵 音乐播放器

- 内置 5 首本地音频（`voice.mp3` / `voice1~4.mp3`）
- 唱片滑动切歌（触屏 + 鼠标拖拽，带边界回弹）
- 播放 / 暂停、进度条点击跳转、时间显示
- 播放列表管理：添加、移除、一键清空（保留当前歌曲）
- 四种播放模式：**顺序 / 列表循环 / 单曲循环 / 随机**
- 移动端后台连续播放优化（接近结尾自动切歌 + 返回前台自动恢复）
- NFC 写入功能（支持的 Android 浏览器：Chrome / Edge，将当前页面链接写入 NDEF 卡片，手机碰卡即开）

### 🔍 在线音乐与歌单

- **在线音乐搜索**：输入歌名或歌手，三源并行搜索——QQ 音乐（结果最准）+ 网易云（干净）+ 酷我（可免登录播放）
- 搜索结果一键播放，或添加到任意歌单
- **网易云歌单导入**：粘贴歌单链接或纯数字 ID，解析后逐首播放 / 一键全部加入播放列表
- 默认歌单「zz的最爱」（内置 5 首本地歌曲）
- 自建歌单：新建、重命名、删除、切换、查看详情、从歌单移除歌曲
- 自建歌单用 `localStorage` 持久化（键名 `lovezz_user_playlists`）

### 📼 BV 音频提取（B 站）

- 输入 **BV 号或 B 站视频链接**，后端解析视频信息并提取音频
- 优先使用视频已有的独立音频轨（DASH）；否则用 **FFmpeg `-c:a copy` 直接分离原音轨，不重新编码**
- 提取结果支持立即播放或加入歌单
- 仅处理公开接口可取得、你有权使用的媒体；不绕过会员、付费、登录或其他访问限制

### 🐱 呆猫八条贴纸互动

项目的主角素材是「呆猫八条」表情包（127 张缩略图 + 2 张透明底 PNG），分为两层：

- **背景层**（`zz-dynamic.js`）：127 张表情包缩略图由 Canvas 按网格铺满全屏，各自独立缓慢漂浮，点击任意一张可随机替换
- **主角层**（页面内联脚本 + `zz-featured.js`）：每次随机出现 6~8 张贴纸浮于卡片/唱片上方（其中 2 张「必保」贴纸会贴到唱片上），另有一层 8 张可点击漂浮卡片；点击任意贴纸可替换，切歌时重新随机
- **陀螺仪跟随**：手机倾斜时两层贴纸平滑跟随视差移动（灵敏度已调低，避免轻微晃动导致过度位移）
- **晃动甩动**：快速晃动手机触发贴纸 shake 动画
- 传感器在首次触摸/点击时申请权限（兼容 iOS 13+ 的 `requestPermission`）

### 🎆 爱心烟花彩蛋

- 主角层实时统计当前出现的图片：当**同时出现 3 张相同图片**时（无论来自随机出现还是点击替换），触发粉色爱心烟花
- 烟花由 96 个「♥」粒子构成，带旋转、重力与发光效果
- 烟花不会改变原本的主角图片状态

### 📱 移动端体验

- 两页式结构：第一页开场胶囊（「surprise❤」+ 打开按钮）→ 第二页纪念卡片（音乐播放 + 全部交互）
- 适配安全区（`env(safe-area-inset-*)`）、`100dvh` 全屏、禁止缩放与回弹
- 粉色渐变背景 + 毛玻璃卡片 + 爱心/蝴蝶等 16 个漂浮表情装饰

## 🔧 后端接口（腾讯云 SCF）

后端为腾讯云 Serverless 云函数（广州区 Web 函数），前端通过 `API_BASE` 调用。同一份代码兼容**事件函数**（`exports.main_handler`）与 **Web 函数**（`scf_bootstrap` + Node 监听 9000）两种部署方式。

| 接口 | 功能 | 说明 |
| --- | --- | --- |
| `GET /api/search?keyword=` | 在线音乐搜索 | QQ + 网易云 + 酷我三源并行，按相关度打分去重排序，过滤有声书/铃声片段 |
| `GET /api/play?id=&source=&name=&artist=` | 音频播放地址 | 302 重定向到真实 CDN（强制 https），QQ 结果自动酷我同名兜底，支持跨平台解析 |
| `GET /api/playlist?id=` | 网易云歌单导入 | 支持完整链接或纯数字 ID，返回歌单名 + 歌曲列表 |
| `GET /api/bv?bvid=` | B 站 BV 音频提取 | 优先 DASH 独立音频轨；环境有 FFmpeg 时 `-c:a copy` 分离原音轨，不重新编码 |
| `GET /api/bvaudio?u=` | B 站音频流代理 | 携带 Referer 转发，按 1MB Range 分片规避响应体限制；仅允许转发到 B 站官方媒体 CDN（防 SSRF） |

> 当前 `index.html` 中配置的 API 地址：`https://1489001692-hcdmisltcl.ap-guangzhou.tencentscf.com`（部署时按实际函数 URL 修改 `API_BASE`）。

## 🚀 部署

1. **前端**：将 `text-main/` 目录发布到 GitHub Pages（项目主页：`lin0110zz.github.io/lovezz`）
2. **后端**：将 `scf/` 部署到腾讯云 SCF（Node.js 运行时），Web 函数填 `scf_bootstrap`，事件函数填 `index.js` 的 `main_handler`
3. **自动注入**：`.github/workflows/enable-zz-dynamic.yml` 会在 push 到 `main` 时自动检查并注入 `zz-dynamic.js` / `zz-featured.js` / `zz-ui.js` 三个脚本标签并提交
4. 部署后端后，将函数 URL 填入 `index.html` 顶部的 `API_BASE`

## 🎮 使用说明

### 音乐搜索

1. 点击播放列表入口栏的搜索框（🔍）
2. 在「搜索结果」页输入歌名或歌手，点搜索
3. 点击结果行播放，或点「+」添加到歌单

### 导入网易云歌单

1. 搜索面板右上角点「📥」按钮
2. 粘贴歌单完整链接（如 `https://music.163.com/#/playlist?id=123456`）或纯数字歌单 ID（需公开）
3. 解析完成后可单首播放，或点「全部加入播放列表」

### 歌单管理

1. 搜索面板切换到「zz的歌单」标签
2. 点击歌单进入详情；点「▶」直接播放整个歌单
3. 右上角「+ 新建歌单」；非默认歌单支持重命名（✏️）与删除（🗑️）
4. 搜索结果的「+」与 BV 提取结果都可以选择加入任意歌单

### BV 音频提取

1. 搜索面板切换到「BV音频」标签
2. 输入 BV 号（如 `BV1xx411c7mD`）或 B 站视频链接，点「变魔法啦dokidoki~」
3. 提取成功后点「▶ 立即播放」或「＋ 加入歌单」

### 贴纸互动

- **陀螺仪**：在支持的移动设备上允许访问设备方向传感器后，贴纸会平滑跟随手机姿态
- **点击替换**：点击背景贴纸或主角贴纸可随机更换图片
- **爱心烟花**：当整个页面同时出现 3 张相同贴纸时自动触发粉色爱心烟花

## ⚠️ 注意事项

1. **在线搜索、网易云歌单导入、BV 提取均依赖后端 SCF**，需先部署后端并正确配置 `API_BASE`，否则相关功能会提示「请检查后端 API 是否已部署」。
2. **自建歌单**保存在浏览器 `localStorage`，清除网站数据后可能丢失；默认歌单为内置 5 首本地歌曲，不依赖存储。
3. **陀螺仪 / 晃动**效果需要设备和浏览器支持 Device Orientation / Motion 传感器；iOS 13+ 与部分 Android 浏览器需用户授权，需在首次触摸/点击后触发。
4. **NFC 写入**仅支持安卓 Chrome / Edge 等支持 Web NFC 的浏览器（不支持微信、QQ、夸克等），且需要空白或可复写的 NDEF 卡片。
5. **BV 提取仅用于你有权使用的视频或音频**，不会绕过会员、付费、登录或其他访问限制。
6. **图片资源较多**（127 张贴纸缩略图），首次打开页面可能需要一定加载时间。
7. 项目内含个人纪念文案与昵称（ZZ & HLM 等），使用前请按需修改。

## 🧰 技术栈

- **前端**：原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- **后端**：Node.js / 腾讯云 SCF（Serverless Function，事件函数 + Web 函数双入口）
- **存储**：浏览器 `localStorage`
- **部署**：GitHub Pages + GitHub Actions + 腾讯云 SCF
- **设备互动**：Device Orientation API / Device Motion API / Web NFC（NDEFReader）
- **媒体处理**：FFmpeg（`-c:a copy` 音轨分离）、B 站 DASH 独立音频轨
- **动画**：Canvas 2D + CSS 动画 + `requestAnimationFrame`
