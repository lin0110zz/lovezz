# 💖 Lovezz 音乐网页 - 搜索&歌单版

基于原项目扩展的音乐网页，新增了**在线音乐搜索**和**多歌单管理**功能。

## ✨ 功能清单

### 原有功能
- 🎵 5首本地音频播放（记得想我、我爱你、几分之几、爱很简单、我不难过）
- 💿 唱片滑动切歌（左右滑动唱片切换歌曲）
- 📋 播放列表管理（增删歌曲）
- 🔄 四种播放模式（顺序/列表循环/单曲/随机）
- 📱 移动端适配（iPhone 15 优化）
- 🔋 息屏后台连播修复
- 📝 NFC 写入功能（安卓 Chrome/Edge）
- ✨ 背景漂浮元素动画

### 新增功能
- 🔍 **在线音乐搜索**：通过歌名或歌手搜索全网音乐（基于歌曲宝 gequbao.com）
- ▶️ **搜索结果即点即播**：点击搜索结果直接播放
- ➕ **添加到歌单**：搜索到的歌曲可添加到任意歌单
- 📁 **多歌单管理**：
  - 默认歌单「我的最爱」（原5首本地歌曲）
  - 用户可自建歌单（新建/重命名/删除）
  - 点击歌单一键切换播放
- 💾 **本地持久化**：自建歌单自动保存到 localStorage，刷新不丢失
- 🎨 **UI 风格统一**：粉色系毛玻璃风格，与原项目完美融合

## 🚀 部署步骤

### 第一步：部署后端到 Vercel

搜索和播放功能需要后端代理（解决跨域和 CDN 防盗链），需要部署到 Vercel。

1. **注册 Vercel 账号**：访问 https://vercel.com ，用 GitHub 账号登录
2. **导入项目**：
   - 点击 "Add New..." → "Project"
   - 导入你的 GitHub 仓库（zz810 对应的仓库）
   - Framework Preset 选择 "Other"
   - 点击 "Deploy"
3. **等待部署完成**：Vercel 会自动识别 `api/` 目录下的文件作为 Serverless Functions
4. **获取后端地址**：部署完成后，Vercel 会给你一个域名，例如 `https://lovezz-xxx.vercel.app`

### 第二步：配置前端 API 地址

1. 打开 `index.html`
2. 找到第 ~1370 行的 `const API_BASE = "";`
3. 改成你的 Vercel 地址，例如：
   ```js
   const API_BASE = "https://lovezz-xxx.vercel.app";
   ```
4. 保存文件

### 第三步：部署前端到 GitHub Pages

1. 将 zz810 项目推送到 GitHub 仓库
2. 在仓库 Settings → Pages 中启用 GitHub Pages
3. 访问 `https://你的用户名.github.io/仓库名/`

## 🎮 使用说明

### 搜索音乐
1. 进入音乐播放器页面（第二页）
2. 点击播放列表栏右侧的 🔍 按钮
3. 在搜索框输入歌名或歌手，点击「搜索」或按回车
4. 搜索结果列表中：
   - 点击歌曲或 ▶ 按钮：直接播放
   - 点击 + 按钮：添加到歌单（可选择已有歌单或新建歌单）

### 歌单管理
1. 打开搜索面板，切换到「我的歌单」标签
2. 查看所有歌单（默认歌单 + 自建歌单）
3. 点击歌单：切换到该歌单播放
4. 点击 ✏️：重命名歌单
5. 点击 🗑️：删除歌单
6. 点击「+ 新建歌单」：创建新歌单

### 播放模式
- 打开播放列表，顶部有四个模式按钮：
  - ☰ 顺序播放
  - 💞 列表循环
  - ❣️ 单曲循环
  - 💗 随机播放

## ⚠️ 注意事项

1. **后端必须部署**：搜索和在线播放功能依赖 Vercel 后端，未部署时搜索会提示"网络错误"
2. **VIP 歌曲**：歌曲宝本身已聚合多平台音源，大部分 VIP 歌曲可直接播放；少数无法播放的歌曲会提示获取失败
3. **本地音频 vs 在线音频**：默认歌单是本地音频（5首），搜索添加的是在线音频（通过后端代理播放）
4. **自建歌单持久化**：自建歌单保存在浏览器 localStorage，清除浏览器数据会丢失
5. **NFC 功能**：仅安卓 Chrome/Edge 浏览器支持，iOS 不支持网页写入 NFC
6. **音频缓存**：在线音频通过后端代理，建议网络良好时使用

## 🔧 技术栈

- **前端**：原生 HTML/CSS/JavaScript（无框架）
- **后端**：Node.js（Vercel Serverless Functions）
- **音源**：歌曲宝 gequbao.com（爬虫代理）
- **存储**：localStorage（歌单持久化）
- **部署**：GitHub Pages（前端）+ Vercel（后端）

## 📝 后端接口说明

### 搜索接口
```
GET /api/search?keyword=周杰伦
```
返回：
```json
{
  "keyword": "周杰伦",
  "count": 20,
  "songs": [
    {"id": "4190", "name": "稻香", "artist": "周杰伦", "title": "稻香 - 周杰伦", "source": "gequbao"}
  ]
}
```

### 播放接口
```
GET /api/play?id=4190
```
返回：音频流（audio/mpeg），支持 Range 请求
